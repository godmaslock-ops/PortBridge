PortBridge v0.16 - QUICK START

PC1 = computer with the Xiaomi phone physically connected.
1. Put the phone in Connect with Mi Assistant.
2. Double-click START_PC1.bat.
3. Leave the window open.

PC2 = computer from which you want to test the remote USB path.
1. Double-click START_PC2.bat.
2. It searches the local network automatically.
3. No CMD commands and no IP address typing are required.

Important:
- Extract the full ZIP before starting.
- Both PCs must be on the same local network for this test build.
- If Windows Firewall asks for access, allow it on the private network.
